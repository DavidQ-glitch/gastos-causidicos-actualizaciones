# Actualizaciones de "Gastos Causídicos y Convenios"

Repositorio de actualizaciones del programa del Dr. Jorge Gustavo David Quintana
(Municipalidad de Moreno). Todos los derechos reservados.

Cada actualización tiene dos archivos en esta carpeta:

- `Causidicos_y_convenios_Moreno.html`: el programa.
- `actualizacion.json`: el aviso con la versión, la huella del archivo y la FIRMA del autor.

El programa sólo instala una versión nueva si la firma corresponde a la clave del autor
(huella de la clave pública: BE6D 58CA 0799 8466) y si el archivo descargado coincide
exactamente con el firmado. Cualquier cambio hecho por otra persona se rechaza.

Para publicar: firmar el HTML con Firmador_actualizaciones.html y subir aquí los dos
archivos, reemplazando los anteriores.
